# sistema-psicologia

Sistema de organização do consultório para psicólogas: agenda, pacientes e registro documental, financeiro com controle de recibos do Receita Saúde, horas de sala alugada, documentos e carreira.

Página estática publicada pelo Netlify, com login e dados no Firebase (projeto sistema-psicologia-f730a). O passo a passo de configuração está em "Passo a passo.md".
